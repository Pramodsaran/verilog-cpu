# verilog-cpu
4-bit CPU built from scratch in Verilog

## Components Built
- Half Adder
- Full Adder  
- Ripple Carry Adder
- 4-bit ALU (ADD, SUB, AND, OR, XOR, NOT)
- D Flip Flop
- 4-bit Register File
- Program Counter
- Instruction Memory
- Fetch Unit
- Control Unit
- Complete CPU Datapath

## Tools Used
- Questa Altera Starter Edition 2025.2

## Simulation Results
CPU successfully fetches, decodes and executes
instructions automatically using a simple
9-bit instruction format.
